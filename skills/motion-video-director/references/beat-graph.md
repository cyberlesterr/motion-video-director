# Beat Graph Contract

Use one object whose state changes as the primary carrier of meaning. Do not begin from slides or pages.

## Required fields

```json
{
  "id": "beat-01",
  "time": "0.0-4.0",
  "narrativeJob": "hook",
  "mainMovingObject": "compressed signal ribbon",
  "stateChange": "a noisy ribbon resolves into three labeled paths",
  "cameraOrLayerMotion": "slow push-in with foreground parallax",
  "textRole": "short title",
  "assetNeed": "SVG paths and local logo",
  "pptRisk": "do not replace the transformation with a static before/after card",
  "proofTimes": [0.8, 2.2, 3.6]
}
```

## Rules

- Use 3–8 beats for a 10–60 second film.
- Assign one narrative job per beat: hook, reveal, contrast, mechanism, consequence, proof, or close.
- Include at least one main moving object and one concrete state change in every beat.
- Use text as an anchor, label, or counter; do not require the viewer to read paragraphs to understand a beat.
- Plan at least three proof times per scene: early change, hero state, and late/final state.
- Name the PPT risk before implementation and verify that the implementation avoids it.
